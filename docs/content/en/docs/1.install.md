description: Vendor the library into a project's vendor/ui with subtree, and commit it there.

Each project vendors this repository into its own `vendor/ui` with subtree, then commits that directory. It is an ordinary directory in the project. Local dev and the remote build compile the same committed files.

The full steps for an agent are in `AGENTS.md` at the repository root. On install, the agent also writes the steps for pushing upstream, pulling upstream, and moving a project component into the library into that project's own agent markdown.

```bash
git subtree add --prefix=vendor/ui https://github.com/0froq/ui.git main --squash
pnpm add ./vendor/ui
```

The dependency uses the file protocol and points at `vendor/ui`.

Edit `vendor/ui/src/...` inside the project, then commit that project. Other projects keep their own copy and do not follow along.

To send this project's changes back upstream, run this from the project root:

```bash
git subtree push --prefix=vendor/ui https://github.com/0froq/ui.git main
```

To catch up with upstream:

```bash
git subtree pull --prefix=vendor/ui https://github.com/0froq/ui.git main --squash
```

## Import

Fonts are not in the package. The components use Instrument Serif, Geist, and Geist Mono. The project loads them. Without them, the page falls back to system fonts.

```ts
import '@froq/ui/style.css'
import { Choice, Toggle } from '@froq/ui'
```

```vue
<div class="ui">
  <Choice
    v-model="tone"
    label="Tone"
    :options="[
      { value: 'quiet', label: 'quiet' },
      { value: 'loud', label: 'loud' },
    ]"
  />
</div>
```

The package ships source (`.vue`, `.ts`, `.css`). The consumer's build compiles it. Vite can use it directly.

## Nuxt

This docs site is wired the same way. `build.transpile` tells Nuxt to compile the `.vue` files in the package.

```ts
export default defineNuxtConfig({
  css: ['@froq/ui/style.css'],
  build: { transpile: ['@froq/ui'] },
})
```
