这些变量定义在作用域类 `.ui` 上。组件只读它们。

`--ui-bg` `--ui-fg` `--ui-muted` `--ui-faint` `--ui-line` `--ui-accent` `--ui-font-display` `--ui-font-text` `--ui-font-meta` `--ui-ease` `--ui-dur` `--ui-radius`

颜色用 `light-dark()`，跟随系统。在自己或祖先上写 `data-theme="light"` 或 `data-theme="dark"` 可以强制。页脚的浅色 / 深色就是在改 `<html>` 的 `data-theme`，作用域跟着变。

作用域是一个类，不是全局。一块区域写上 `class="ui"`，那一块就用这些变量。

只想要 token、不用组件，单独引 `@froq/ui/tokens.css`。

`pnpm check:tokens` 会检查这些变量都有定义。
